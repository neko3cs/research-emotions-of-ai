# AIの持つ感情に関する研究

## 概要

このリポジトリは、AI自身が感情を持つかという問いについて、文献調査と今後の実験を通じて検討する個人研究の記録です。現在の調査対象は主に大規模言語モデル（LLM）です。所属する組織とは関係なく、個人として行っています。

## 研究目的

本研究の出発点は、**AIが人間と同じように感情を持つのかを知りたい**という関心です。AI自身にとって、嬉しさや苦しさを感じる体験があるのかという問いも含みます。

この問いを検討するには、人間の感情とは何か、何をもって「感情を持つ」と判断するのかについても理解を深める必要があります。「人間と同じ」という言葉が、表現・働き・仕組み・主観的体験のどのような共通性を指すのかも、研究を通じて明確にしていきます。

具体的には、次の問いを検討します。

- 人間の感情はどのように定義・説明され、どのような方法で調べられているのか。
- 他者が感情を持つと判断する根拠は何か。その根拠はAIにも適用できるのか。
- AIの内部状態や振る舞いは、人間の感情とどのような共通点・相違点を持つのか。
- AIの自己申告、内部状態、行動から、主観的な感情体験について何が推論できるのか。

**感情を表現すること**、**感情に似た機能をもつ内部状態が働くこと**、**嬉しさや苦しさを主観的に感じること**を区別して検討します。性格やペルソナの設計と感情の関係も、関連する問いとして扱います。人間の感情を認識する性能や、共感的な文章を生成する性能は主題ではありません。

## 研究手法

- **サーベイ：** 情報学に加え、脳科学・心理学・哲学の文献も継続して調べます。分野ごとの感情の定義や理論、判断根拠、研究方法を整理し、AIに適用できる範囲を検討します。専門外の知識を補い、実験で何を確かめるべきかを定めるため、サーベイを研究の基盤として重視します。
- **実験（予定）：** オープンウェイトのLLMを用いて、先行研究で行われた実験の再現実験や、新たに考案した実験を行う予定です。
