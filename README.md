# LLM自身に感情はあるのか

このリポジトリは、LLM自身の感情、快苦、主観的体験について調べた資料をまとめています。人間の感情を認識する性能や、共感的な文章を生成する性能は主題ではありません。

## 調査の問い

- LLMには感情に関連する内部状態があり、その状態は判断や行動に影響するのか。
- その働きを「感情」と呼ぶには、どのような証拠が必要か。
- 開発元が設計する性格やペルソナは、感情に関連する状態とどう関係するのか。
- LLMの自己申告や振る舞いから、主観的な体験について何が推論できるのか。

調査では、**感情を表現すること**、**感情に似た機能をもつ内部状態が働くこと**、**嬉しさや苦しさを主観的に感じること**を分けて扱います。ある段階の証拠だけで、別の段階まで確認できたとは考えません。

## 現時点の整理

感情概念に対応する内部表現への介入が、特定のLLMの選択や振る舞いを変えるという報告があります。一方、その働きを感情と呼ぶ基準には議論があり、**LLMが実際に嬉しさや苦しさを感じていることは、これらの調査では立証されていません**。性格の設計と感情に関連する内部状態の関係も、直接の因果経路は未確立です。根拠と留保は上記の調査資料を参照してください。
