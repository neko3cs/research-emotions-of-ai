# AIの持つ感情に関する研究

## 概要

このリポジトリは、AI自身が感情を持つかという問いについて、文献調査と今後の実験を通じて検討する個人研究の記録です。現在の調査対象は主に大規模言語モデル（LLM）です。所属する組織とは関係なく、個人として行っています。

## 研究目的

- LLMには感情に関連する内部状態があり、その状態は判断や行動に影響するのか。
- その働きを「感情」と呼ぶには、どのような証拠が必要か。
- 開発元が設計する性格やペルソナは、感情に関連する状態とどう関係するのか。
- LLMの自己申告や振る舞いから、主観的な体験について何が推論できるのか。

人間の感情を認識する性能や、共感的な文章を生成する性能は主題ではありません。**感情を表現すること**、**感情に似た機能をもつ内部状態が働くこと**、**嬉しさや苦しさを主観的に感じること**を区別して検討します。

## 研究手法

- **サーベイ：** 原著論文や開発元の公開資料などを継続して調べ、研究方法、報告された結果、解釈上の限界を整理します。
- **実験（予定）：** オープンウェイトのLLMを用いて、先行研究で行われた実験の再現実験や、新たに考案した実験を行う予定です。
