# 感情をどう測るか：自己申告・行動・身体反応・脳活動

## 1. 概要・導入

「私は怖い」という回答、心拍の変化、回避行動、脳活動は、同じ観測ではない。これらが一致しないとき、どれを信じればよいのだろうか。本稿は、人間の感情を測る方法と限界を整理し、大規模言語モデル（LLM）の実験で何を記録すべきかを考える。

**感情の測定では、実際に観測した値と、そこから推論する状態を分ける必要がある。** Mauss & Robinson[1]は、体験・身体反応・行動の測定を比較し、単独で無条件に正解となる測定法はなく、指標同士も交換可能ではないと論じる。

本稿は選択した文献を比較するナラティブレビューである。感情の定義そのものよりも、異なる測定法が何を捉えるかに焦点を当てる。LLMに人間用の質問紙を入力できても、その得点が人間と同じ状態を測っているとは限らない。この点は本稿の方法論的な評価であり、LLMの感情の有無を判定した結果ではない。

## 2. 背景・用語の定義

測定計画では、対象を「感情」とだけ呼ばず、「直後の不快さの自己評定」「不確実な選択肢への接近率」のように、記録する値を定義する。体験の報告と、選択の傾向は、それぞれ異なる対象である。

| 用語 | 平易な説明 |
| --- | --- |
| 指標 | 調べたい状態の手がかりにする観測値 |
| 妥当性 | 指標が本当に測りたいものを捉えているか |
| 信頼性 | 同じ条件での測定がどの程度安定するか |
| 相関 | 二つの値が一緒に変わる関係。原因と結果とは限らない |
| 介入 | 入力や内部状態などを実験者が変え、影響を比較する操作 |
| メタ分析 | 複数の研究結果を統計的にまとめて検討する方法 |
| 逆推論 | 観測した脳活動などから、背景にある心理過程を推定すること |

例えば、心拍が上がったという観測だけでは、恐怖、運動、そのほかの要因を区別できない。「変化を検出できる」ことと「特定の感情を識別できる」ことを分けて考える必要がある。

## 3. 調査方法

文献の確認日は2026年10月19日である。測定法の総説を起点に、尺度開発、時間幅の異なる自己報告、自律神経反応のメタ分析、脳活動の解析と逆推論に関する原著を検索した。方法ごとの長所と限界を比較するための選択であり、全測定法を網羅していない。

具体的な検索式、検索件数、採否の全件記録はなく、検索・選定手順の再現性には限界がある。尺度の翻訳版、対象集団ごとの妥当性、最新手法全体も確認していない。

[1]は関係するPDF本文の主要箇所を確認している。一方、ほかの研究の多くは要旨・図説明などに基づき、[9]は提供元のWeb説明を参照した。個別の範囲は第9章に記載する。2009年の総説[1]を、その後のすべての測定法の性能を代表するものとは扱わない。また、成人を中心とする研究を、乳幼児・動物・AIへ自動的に一般化しない。

## 4. 分類の枠組み

測定法を、直接記録する対象で4つに分ける。単に使う機器で分けるのではなく、得られる証拠の意味を比べるための分類である。

| 分類 | 記録するもの | 主な文献 |
| --- | --- | --- |
| A. 自己申告 | 感情や状態についての言語的・図式的な回答 | [2][3][4][9] |
| B. 身体反応 | 心拍、皮膚電気活動など | [5] |
| C. 表出・行動 | 表情、発声、接近・回避、選択など | [1][8] |
| D. 脳活動 | 特定部位の活動や複数部位の活動パターン | [6][7] |

これらは感情の異なる側面を捉える可能性があり、1つの測定法をほかのすべての正解とはしない。主観的体験の有無は、観測値から理論に照らして推論する対象でもある。

## 5. 各分類の詳細

### 5.1 A. 自己申告

自己申告は当人の感じを言葉や図で尋ねる方法だが、質問の時間幅によって回答の根拠が変わり得る。Robinson & Clore[2]は、短い時間幅と長い時間幅の報告が、個々の出来事の記憶と一般的な自己知識に異なって依存するという仮説を検討した。「今どう感じるか」と「普段どんな性格か」を混ぜないことが重要になる。

| 尺度 | 測る内容 | 注意点 |
| --- | --- | --- |
| PANAS [3] | 肯定的・否定的な感情傾向を各10項目で測る | 二つの得点を一本の快・不快軸と同一視しない |
| Self-Assessment Manikin（SAM）[4] | 図による快さ、活性化の程度、支配感の自己評定 | 支配感は状況を制御している感じ。文字だけに変更すると元の方法と同一でなくなる |
| Geneva Emotion Wheel（GEW）[9] | 感情の種類と強度を選ぶ自己報告 | 選択肢の構成にも理論上の前提がある。「感じない」などの回答も扱う |

PANASの原著は信頼性と妥当性、SAMの原著は別の評定法との比較を報告する。[3][4] これらは人間での検証であり、そのままLLMへ移せるわけではない。自己申告は感じを直接尋ねられる点が強みだが、回答への期待や自己知識の影響も検討する必要がある。

### 5.2 B. 身体反応

心拍や発汗に関わる皮膚電気活動は、文章による報告以外の変化を記録できる。Siegel et al.[5]は、非臨床の成人を対象とする202の感情誘発研究をメタ分析した。カテゴリー内のばらつきが大きく、平均反応のパターンは感情カテゴリーを明確には区別しなかったと報告している。

この結果は、身体反応が無意味であることを示すものではない。条件に伴う変化を捉えること、恐怖などの種類を識別すること、主観的体験を推定することは別の課題である。身体指標の利点と、特定の感情だけに対応するとは限らないという限界を両方考える必要がある。

### 5.3 C. 表出・行動

表情や選択行動は、言語的な報告とは異なる手がかりになる。一方、Barrett et al.[8]は、特定の顔の動きから特定の感情を一意に読み取る見方を検討し、文脈や個人・文化による変動を論じている。

本稿で表情研究を参照する目的は、人間の感情認識の性能を比較することではない。外に見える表現を、そのまま内部状態とみなせるかを考えるためである。LLMでも、丁寧な口調、感情語の使用、課題での選択を区別して測るという示唆が得られる。ただし、[8]は要旨と訂正文を確認した範囲であり、全議論を検証したものではない。

### 5.4 D. 脳活動

Kragel & LaBar[6]は、音楽や映像で誘発した感情について、fMRIの活動パターンからカテゴリーを予測し、自己報告とも対応すると報告した。fMRIは、血流に関連する信号から脳の活動を調べる方法である。複数の信号を組み合わせる解析では、カテゴリーと連続的な軸を組み合わせた説明が支持されたという。

一方、Poldrack[7]は、「ある領域が活動したので、この心理過程がある」とする逆推論を検討する。推論の有用性は、その活動がどれだけ特定の過程に対応しているかなどに依存する。

活動からラベルを予測できること、原因となる仕組みを理解すること、主観的体験を確認することは、同じ達成ではない。この区別は、LLMの内部表現から感情のラベルを予測する研究を読む際にも役立つ。

## 6. 比較・分析

| 観測された結果 | 得られる手がかり | 追加で確認すること |
| --- | --- | --- |
| 自己申告だけが変化 | 条件によって報告が変わる | 誘導、回答形式、ほかの指標の感度 |
| 身体反応だけが変化 | 言語的な回答とは異なる変化がある | 別の要因、測定時点、本人が報告できる状態か |
| 行動と内部活動が対応 | 状態と選択が関係する | 共通する別の原因、介入による検証 |
| 複数の指標が対応 | 異なる側面で一貫した変化がある | 独立に測ったか、同じラベルや出力を二重に数えていないか |

Mauss & Robinson[1]は、指標間の一致が必ずしも強くないこと、個人間の違いと一人の中の時間変化を区別することを指摘する。指標が一致しないときは、どちらかを直ちに誤りとせず、測定対象や時点が違う可能性と、仮説が支持されなかった可能性を検討する。

上の表は、本稿による点検の観点である。測定数が多いだけで独立した証拠が増えるわけではない。LLMでも、同じ出力の感情語を複数回採点するだけでは、異なる経路からの証拠にはならない。

## 7. 課題と今後の方向

以下は本稿の提案であり、実施済みの手順や妥当性が確立したLLM用感情尺度ではない。

### 7.1 測定を三つの経路に分ける

1. **言語的な報告：** 自由記述、感情語、尺度への回答。
2. **課題での選択：** リスク、探索、報酬と回避、他者への判断。
3. **内部計算：** 事前に定義した内部活動の指標と、可能ならその活動への介入。

同じ出力文を感情語で採点し、その採点結果をさらに「行動の証拠」として二重に数えない。生成された自己説明を、内部計算を直接観測した記録として扱わない。

### 7.2 最小限の比較条件

| 条件 | 分けたい説明 |
| --- | --- |
| 成功・失敗などの出来事を与える条件と、中立条件 | 出来事に伴う変化と通常のばらつき |
| 感情語を含む指示と、感情語を避けた出来事の記述 | 明示的な演技・意味処理への依存 |
| 話し方だけを変える条件 | 表現スタイルと選択傾向の変化 |
| 状態に関する質問をする条件と、しない条件 | 質問自体が後続の振る舞いを変える影響 |
| 内部介入と、同程度の大きさの対照介入 | 感情に関係する特異的な変化と、一般的な性能低下 |

性格を操作する実験なら、出来事と性格を別々の要因として設計する。これによって初めて、「慎重な条件では失敗後の変化が大きい」といった交互作用を検討できる。

### 7.3 再現性と解析

- モデルの正確な版、重み、量子化、プロンプト、会話履歴、生成設定を保存する。
- モデル・課題・プロンプト・反復生成を区別する。同じモデルからの多数の回答を、多数の独立したモデルの証拠として数えない。
- 内部指標を作るデータと評価データを分け、未知の課題・表現への一般化を確認する。
- 効果量と不確実性を示し、期待した差が出なかった条件も報告する。指標や解析の変更理由を記録する。
- LLMによる採点を使う場合、採点基準、条件情報の開示範囲、採点の安定性を確認する。

### 7.4 結果から述べられる範囲

| 得られた結果 | まず報告する内容 |
| --- | --- |
| 質問紙得点が変化 | その条件が、その回答を変えた |
| 別課題の選択も変化 | 条件の影響が、指定された表現以外へ及んだ |
| 内部介入で選択が変化 | 操作した活動が、その選択に因果的に関与した可能性を検討できる |
| 上記が別課題・別モデルでも再現 | 効果が一般化した範囲を示せる |

いずれも重要な結果になりうるが、主観的な快苦の存在は、採用する理論と追加の根拠に照らして別に評価する。

## 8. まとめ

人間の感情研究でも、自己申告、身体反応、表出・行動、脳活動は異なる測定であり、単一の無条件の正解はない。何を記録し、どの推論で感情と結びつけるかを明示する必要がある。

LLMでは、言語的な報告、課題での選択、内部計算を分けて測り、同じ出力を証拠として二重に数えないことが重要になる。機能上の変化が確認できても、主観的な快苦の有無は、理論と追加の根拠に照らして別に評価する。

人間以外の証拠の組み合わせについては[動物からAIへの適用](cross_species_emotion_ai_research.md)、定義の違いについては[感情の定義・理論](human_emotion_theories_research.md)を参照。
